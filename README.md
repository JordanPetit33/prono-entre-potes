# Prono entre potes

Ce que fait l'outil : il permet de saisir des pronostics de score sur les matchs de foot, calcule les points une fois les résultats connus et tient un classement entre amis.
Pour qui : un petit groupe d'amis qui veut se challenger sur chaque journée de championnat.
Ce qu'il ne fera pas : pas de paris d'argent, pas de récupération automatique des résultats (saisie manuelle), pas de comptes utilisateurs ni de synchro en ligne pour l'instant, une seule compétition à la fois.
